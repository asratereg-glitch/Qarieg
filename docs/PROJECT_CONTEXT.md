# قارئ (Qari) — ملف سياق المشروع

## الرؤية
تطبيق ويب لقراءة الكتب، عربي أولًا (RTL كامل) مع دعم إنجليزي، يشتغل من المتصفح مباشرة بدون سيرفر وبدون تسجيل دخول. كل البيانات على جهاز المستخدم (خصوصية كاملة) مع تصدير/استيراد للنسخ الاحتياطي والمشاركة.

## المستخدم والأسلوب
- المستخدم الأساسي عربي (مصري)، لذلك الواجهة عربية افتراضيًا مع زر تبديل للإنجليزية.
- الخطوط: Amiri للقراءة العربية، Cairo للواجهة، مع خطوط لاتينية للكتب الإنجليزية.
- الهوية البصرية: دافئة (سيبيا افتراضيًا)، هادئة، تركيز على النص.

## المعمارية التقنية
- **بدون باك إند**: Static site خالص — HTML + CSS + JavaScript (ES Modules)، بدون خطوة بناء.
- **التخزين**:
  - ملفات الكتب (EPUB/PDF/TXT): IndexedDB (`qari-files`).
  - الحالة (مكتبة، تقدم، هايلايتس، جلسات، أهداف): localStorage تحت مفتاح `qari.state.v1` مع ترحيل نسخ.
- **قراءة EPUB**: مكتبة epub.js (مُضمّنة محليًا `js/vendor/`) — تعمل بوضع صفحات أو تمرير.
- **قراءة PDF**: مكتبة pdf.js v3 (مُضمّنة محليًا مع الـ worker).
- **الأوفلاين**: Service Worker (`sw.js`) يخزّن هيكل التطبيق، والكتب محفوظة أصلًا في IndexedDB — التطبيق كله يشتغل بدون نت بعد أول فتح.
- **مصدر بيانات الكتب الخارجي**: Open Library API (بحث بالعنوان/ISBN، أغلفة، مواضيع للترشيحات) — مجاني وبدون مفتاح.
- **القاموس**: dictionaryapi.dev للإنجليزية + رابط ترجمة للعربية (يحتاج نت، والتطبيق يوضح ده بصراحة).
- **TTS**: Web Speech API المدمجة في المتصفح (أصوات عربي/إنجليزي حسب الموجود على الجهاز).

## حدود صريحة (قرارات تصميم)
الميزات اللي بتحتاج سيرفر وحسابات اتنفذت ببدائل محلية صادقة:
- **المزامنة بين الأجهزة** → حفظ تلقائي فوري + تصدير/استيراد ملف بيانات JSON.
- **متابعة الأصدقاء** → تسجيل تقييمات ومراجعات محلية + نشاط قابل للتصدير ومشاركته.
- **القراءة المشتركة** → تعليقات فصول باسمك واسم صاحبك، مع دمج تعليقات الطرفين عن طريق تصدير/استيراد JSON.
أي إضافة باك إند مستقبلًا لن تغيّر نموذج البيانات؛ الواجهات معزولة في `store.js`.

## بنية الملفات
```
qari-app/
├── index.html          الهيكل والقوالب
├── css/styles.css      التصميم (ثيمات + RTL)
├── js/
│   ├── vendor/         epub.js, jszip, pdf.js (محلية)
│   ├── db.js           طبقة IndexedDB
│   ├── store.js        الحالة والترحيل
│   ├── i18n.js         الترجمة عربي/إنجليزي
│   ├── app.js          الراوتر + المكتبة + الرفوف + الإعدادات
│   ├── reader.js       القارئ (EPUB/PDF/TXT، هايلايت، TTS، قاموس)
│   ├── stats.js        الأهداف، الـ streak، الجلسات، الملخص السنوي
│   ├── discover.js     البحث، الترشيحات، الجوائز، بحث المزاج
│   └── community.js    التقييمات، المراجعات، القراءة المشتركة
├── data/               (بيانات الجوائز والمزاج مضمّنة في discover.js)
├── fonts/              Amiri + Cairo (woff2)
├── sw.js               Service Worker
└── docs/               التخطيط والسياق
```

## معايير الجودة المتفق عليها (QC Gate)
1. يفتح من `file://` وسيرفر محلي بدون أخطاء Console.
2. تحميل EPUB وPDF وTXT حقيقي والتنقل بين الصفحات.
3. الثيمات الثلاثة + حجم الخط + RTL/LTR تنعكس فورًا.
4. إغلاق وفتح القارئ يرجع لنفس المكان.
5. هايلايت + ملاحظة يتحفظوا ويظهروا ويتصدروا Markdown.
6. الأهداف والـ streak يتحدثوا بعد جلسة قراءة مسجلة.
7. كل شاشة تتصوّر وتتراجع بصريًا (لقطات في تقرير QC).
