# قارئ — Qari 📖

تطبيق ويب لقراءة الكتب: عربي أولًا، يشتغل من المتصفح، بدون سيرفر، وكل بياناتك على جهازك.

## التشغيل
أي واحدة من دول:
1. **الأسهل**: دوس مرتين على `index.html` (لازم تفك الـ zip الأول، متفتحوش من جوه الـ zip). v1.0.1 بيشتغل من غير سيرفر.
   أو دوس على `start.bat` (لو Python متسطّب) عشان يشغّل سيرفر محلي ويفتح المتصفح.
2. **سيرفر محلي** (يفعّل وضع الأوفلاين بالكامل):
   ```bash
   cd qari-app && python3 -m http.server 8080
   # ثم افتح http://localhost:8080
   ```

## الاستخدام
- **أضف كتاب** ← من جهازك (EPUB / PDF / TXT) أو ابحث أونلاين بالعنوان/ISBN (من Open Library).
- اضغط على الكتاب ← **ابدأ القراءة**. مكانك بيتحفظ تلقائيًا.
- في القارئ: السهمان للتقليب، ⚙ للثيم والخط، 🔊 للقراءة الصوتية، 🖊 للهايلايتس.
- حدّد أي جملة → هايلايت بلون، أو ملاحظة، أو قاموس/ترجمة.
- **إحصائياتي**: أهداف السنة والشهر، أيام القراءة المتواصلة، الأوسمة، والملخص السنوي.
- **اكتشف**: ترشيحات حسب تقييماتك، قوائم جوائز Hugo/Nebula/Booker، وبحث بالمزاج.
- **المجتمع**: تقييماتك ومراجعاتك، وتعليقات فصول للقراءة المشتركة مع صاحبك (تصدير/استيراد ودمج).
- **الإعدادات**: لغة الواجهة، الثيم، تصدير/استيراد كل بياناتك (JSON).

## v1.1.2
- Discover top lists are now a category tree: Fiction / Non-fiction / Other, with genres and sub-genres under each (e.g. Fiction > Science fiction > Dystopian).
- Fiction categories return novels only (subject must be Fiction, criticism/non-fiction excluded). Non-fiction excludes fiction. Works with Open Library and Google Books (Google results filtered by category).
- The Google Books API key is saved in the .qari database file (it lives in settings) and now saves as you type.
- Categories follow Goodreads' genre names (Fiction/Non-fiction/Other). Goodreads has no public API; connect your data via Goodreads CSV export (Lists tab > import). Goodreads RSS is not usable from a browser page (no CORS headers, checked live), so it is not included.

## v1.2.0
- GitHub sync (Settings > Sync across devices): saves data.json (library, progress, notes, highlights, lists, settings) and book files to a PRIVATE repo (default `qari-data`) through the GitHub contents API. Token (fine-grained, Contents read/write on that repo only) is stored on the device only. Auto-pull on open/focus/every 90s, auto-push 12s after a change, "Sync now". Last write wins; a warning banner appears on conflict and the overwritten local copy can be downloaded. Google Books key and Open Library cache are not synced.
- Hosted on GitHub Pages: manifest + icons for Add to Home Screen.
